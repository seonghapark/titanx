📋 COMMAND OPTIONS

Required:
  --model-path PATH              Path to checkpoint (distcp or HF format)

Mode:
  --mode single|multi            Training mode (default: single)

Hostfile (optional in PBS jobs):
  --hostfile FILE                Use explicit hostfile (not needed with PBS_NODEFILE)

Conversion:
  --output-dir DIR               Where to save converted models
  --delete-converted             Delete converted model after training

Execution:
  --dry-run                      Preview without running
  --verbose                      Verbose output
  --help                         Show help message

Training (after --):
  --training.steps N             Total training steps
  --training.seq_len N           Sequence length

🔧 TROUBLESHOOTING

Error: "Multi-mode requires either --hostfile or PBS_NODEFILE"
  ✓ You're not in a PBS job and didn't provide --hostfile
  ✓ Solution: Submit as PBS job or use --hostfile

Error: "Checkpoint path does not exist"
  ✓ Path is wrong or relative
  ✓ Solution: Use absolute path, verify it exists first

Model conversion takes too long
  ✓ Running on launch node
  ✓ Solution: Pre-convert model once, reuse for multiple runs
