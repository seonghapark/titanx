================================================================================
WHERE THE NAME COMES FROM
================================================================================

CALL FLOW FOR agpt_2b_yarn:
───────────────────────────

1. User runs: ./run_train_torchtitan.sh single -- --module agpt --config agpt_2b_yarn

2. Shell script (run_train_torchtitan.sh):
   - Prints the module/config as-is
   - Passes to trainer as command-line args

3. Python trainer entry point (titan_train.py):
   - Receives --module agpt --config agpt_2b_yarn
   - Passes to ConfigManager

4. ConfigManager:
   - Looks up agpt module in torchtitan/models/agpt/
   - Finds config_registry.py
   - Looks for agpt_2b_yarn() function (line 404)
   
5. agpt_2b_yarn() function calls:
   → agpt("2b_yarn", ...)  (line 413)

6. agpt() function calls:
   → _base_config("2b_yarn")  (line 127)

7. _base_config() calls:
   → model_registry("2b_yarn")  (line 157)

8. model_registry() does:
   → config = agpt_configs["2b_yarn"]  (line 694)
   → Returns ModelSpec(name="agpt", flavor="2b_yarn", ...)

9. ModelSpec is stored in Trainer.Config.model_spec

10. Trainer logs it via:
    → config.model_spec.name        = "agpt"
    → config.model_spec.flavor      = "2b_yarn"
