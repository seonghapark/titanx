KEY FACTS AT A GLANCE
================================================================================

train_agpt20b_yarn.sh
  • Purpose: Train agpt-20b with YaRN context extension
  • Interface: ./train_agpt20b_yarn.sh <seq_len> <steps> <nodes>
  • Parameters: 3 positional arguments
  • Customization: Limited (but covers 95% of use cases)
  • Best for: Data scientists, quick training
  • Learning curve: Gentle
  • One-command launch: Yes ✅

run_train_torchtitan.sh
  • Purpose: Train ANY TorchTitan model with full control
  • Interface: export VAR=val; ./run_train_torchtitan.sh <mode>
  • Parameters: 20+ environment variables + flags + extra args
  • Customization: Complete (every option configurable)
  • Best for: ML engineers, researchers, diverse workloads
  • Learning curve: Steeper
  • One-command launch: No (multiple exports first)

================================================================================
FIVE MINUTE SUMMARY
================================================================================

train_agpt20b_yarn.sh is a wrapper script that:
  1. Takes 3 simple positional arguments (seq_len, steps, nodes)
  2. Validates YaRN configuration
  3. Sets up environment variables
  4. Calls run_train_torchtitan.sh

run_train_torchtitan.sh is a flexible launcher that:
  1. Takes mode (single/multi) + optional hostfile
  2. Accepts 20+ configurable environment variables
  3. Builds complete TorchTitan command
  4. Calls run_train.sh (MPI/PBS wrapper)

Choose train_agpt20b_yarn.sh if:
  ✓ You're training agpt-20b specifically
  ✓ You want one simple command
  ✓ Standard parameters work for you

Choose run_train_torchtitan.sh if:
  ✓ You need to train a different model
  ✓ You need advanced customization
  ✓ You want resource monitoring
  ✓ You need to pass custom TorchTitan arguments
