RESPONSIBILITY DIAGRAM
================================================================================

train_agpt20b_yarn.sh handles:
  ✓ Parse positional arguments
  ✓ YaRN-specific validation
  ✓ Path resolution for agpt-20b
  ✓ Environment setup for YaRN
  ✓ Determine single/multi mode
  ✗ Everything else → delegates

run_train_torchtitan.sh handles:
  ✓ Parse mode and flags
  ✓ Merge environment variables
  ✓ Validate paths and dependencies
  ✓ Build TorchTitan command
  ✓ Optional: resource monitoring wrapper
  ✗ MPI/PBS orchestration → delegates
