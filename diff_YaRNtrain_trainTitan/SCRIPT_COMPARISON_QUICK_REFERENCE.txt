WHAT EACH SCRIPT DOES
================================================================================

train_agpt20b_yarn.sh (107 lines)
  └─ Opinionated wrapper for agpt-20b YaRN training
     • Hardcodes model, module, config
     • Takes 3 positional args: seq_len, training_steps, num_nodes
     • Pre-validates YaRN config
     • Delegates to run_train_torchtitan.sh

run_train_torchtitan.sh (314 lines)
  └─ Universal TorchTitan launcher for ANY model
     • Flexible configuration via environment variables
     • Takes mode (single|multi) + optional hostfile + flags
     • Builds full TorchTitan command with all options
     • Delegates to run_train.sh (MPI/PBS wrapper)


ONE-LINE SUMMARY
================================================================================

train_agpt20b_yarn.sh  = Simple button: "Train agpt-20b with YaRN"
run_train_torchtitan.sh = Full control panel for TorchTitan


QUICK COMPARISON
================================================================================

INTERFACE

train_agpt20b_yarn.sh:
  $ ./train_agpt20b_yarn.sh 16384 400 8

  Args: SEQ_LEN TRAINING_STEPS NUM_NODES (positional)

run_train_torchtitan.sh:
  $ export MODULE=agpt CONFIG=agpt_20b_yarn MODEL_PATH=...
  $ ./run_train_torchtitan.sh multi /hostfile

  Args: MODE [HOSTFILE] [FLAGS] [-- EXTRA_ARGS]
        Environment variables configure everything


WHAT YOU CONTROL
================================================================================

train_agpt20b_yarn.sh — Limited
  ✓ Can change: seq_len, training_steps, num_nodes
  ✓ Can override: CKPT, DATASET_NAME, TP/PP/CP
  ✗ Cannot change: model, module, config, paths
  ✗ No resource monitoring or dry-run

run_train_torchtitan.sh — Full control
  ✓ Can change: module, config, model, dataset, all hyperparams
  ✓ Can enable: resource monitoring, loss std termination, dry-run
  ✓ Can pass: unlimited extra TorchTitan arguments
  ✓ Can customize: logging, checkpointing, all 20+ variables


WHEN TO USE EACH
================================================================================

USE train_agpt20b_yarn.sh IF:

  ✓ Training agpt-20b with YaRN (specifically)
  ✓ Want the simplest command possible
  ✓ Not comfortable with shell scripting
  ✓ Running standard training (seq_len, steps, nodes)
  ✓ Want clear, YaRN-specific error messages
  ✓ New to ML/training, prefer opinionated defaults

EXAMPLE USERS:
  • Data scientist extending context length
  • Student learning YaRN
  • Practitioner running standard workload


USE run_train_torchtitan.sh IF:

  ✓ Training any TorchTitan model (not just agpt-20b)
  ✓ Need fine-grained control over options
  ✓ Want resource monitoring or advanced features
  ✓ Experimenting with different configurations
  ✓ Need custom TorchTitan arguments
  ✓ Running unusual/complex training setups

EXAMPLE USERS:
  • ML engineer optimizing training
  • Framework developer
  • Researcher comparing configs
  • DevOps managing diverse workloads


SIDE-BY-SIDE EXAMPLE
================================================================================

TASK: Train agpt-20b with YaRN, 16K length, 400 steps, 8 nodes

train_agpt20b_yarn.sh:
  $ ./train_agpt20b_yarn.sh 16384 400 8

  One command. Done.

run_train_torchtitan.sh:
  $ export MODULE=agpt
  $ export CONFIG=agpt_20b_yarn
  $ export MODEL_PATH=/lus/flare/projects/datascience/seonghapark/agpt-20b-v2-512n-step-4000-safetensors
  $ export CKPT=/path/to/step-4000
  $ export SEQ_LEN=16384
  $ export TRAINING_STEPS=400
  $ ./run_train_torchtitan.sh multi /path/to/hostfile

  Six setup commands + one launch command.

CONFIGURATION COMPARISON
================================================================================

train_agpt20b_yarn.sh — Hardcoded:
  MODEL_NAME            = "agpt-20b-v2-512n-step-4000"
  SAFETENSORS_PATH      = Fixed path
  MODULE                = "agpt"
  CONFIG                = "agpt_20b_yarn"
  ACTIVATION_CHECKPOINT = "none"
  Dataset               = "pg19_multinews" (overridable)
  DCP path              = Default (overridable via CKPT)

run_train_torchtitan.sh — All configurable:
  MODEL                 = Env var (required)
  MODULE                = Env var (default: llama3)
  CONFIG                = Env var (default: llama3_debugmodel)
  DATASET_NAME          = Env var (default: pg19_multinews)
  DATASET_PATH          = Env var (optional)
  HF_ASSETS_PATH        = Env var (default: MODEL)
  TRAINING_STEPS        = Env var (default: 100)
  SEQ_LEN               = Env var (default: 16384)
  LOG_DIR               = Env var (auto-generated)
  CKPT_FOLDER           = Env var (default: checkpoint)
  TORCHTITAN_ROOT       = Env var (default: ./torchtitan_repo)
  TRAIN_PYTHON_BIN      = Env var (auto-detected)
  RESOURCE_MONITOR      = Env var (default: 0)
  ... and 8 more resource monitoring variables

HIDDEN ASSUMPTIONS
================================================================================

train_agpt20b_yarn.sh assumes:
  • You're training agpt-20b specifically
  • You want CONFIG=agpt_20b_yarn
  • You want MODULE=agpt
  • You want pg19_multinews dataset (unless overridden)
  • You're running from xpu_launcher/xpu_torchtitan/
  • You have DCP checkpoint at standard path (unless CKPT set)
  • You want activation_checkpoint="none"

run_train_torchtitan.sh assumes:
  • You know what MODULE/CONFIG you want
  • You know how to set environment variables
  • You're comfortable with TorchTitan arguments
  • You may customize everything
