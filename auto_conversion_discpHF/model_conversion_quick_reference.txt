================================================================================
MODEL FORMATS
================================================================================

HF Format (Hugging Face) - PREFERRED
  ├── config.json
  ├── model.safetensors (or pytorch_model.bin)
  ├── tokenizer.json
  └── [other assets]
  ✓ Ready for TorchTitan training
  ✓ Compatible with HF ecosystem

DCP Format (Distributed Checkpoint) - NEEDS CONVERSION
  ├── __0_0/
  │   ├── model_state_dict-*.pt
  │   └── ...
  ├── metadata.json
  └── [config if available]
  ✗ Not compatible with TorchTitan directly
  ✓ Can be converted to HF automatically

================================================================================
FORMAT DETECTION
================================================================================

HF Format Detected If:
  ✓ Has config.json
  ✓ Has model weights (.safetensors, .bin, etc)

DCP Format Detected If:
  ✓ Has __0_0 directory (sharded)
  ✓ Has metadata.json
  ✓ Has PyTorch checkpoint files (.pt, .bin)

Check Format:
  python3 convert_model_format.py --check-format /model

  Output:
  ✓ Model is in Hugging Face format
  ✗ Model is in DCP format (needs conversion)
  ? Format is unknown

CONVERSION OPTIONS

Single Model Conversion:

    --dcp /path/to/dcp/model \

With Training Wrapper:

    [--verbose]

================================================================================
COMMON ISSUES & SOLUTIONS
================================================================================

Issue: "Model is in DCP format (needs conversion)"
  Solution 1: Use auto-conversion wrapper
    ./start_training_with_conversion.sh --model-path /model
  Solution 2: Convert manually first
    python3 convert_model_format.py --dcp /model --output /model_hf

Issue: "Could not load DCP checkpoint"
  Solution: Check checkpoint exists and has correct structure
    ls -la /path/to/dcp/
    python3 convert_model_format.py --check-format /path/to/dcp

Issue: "No module named 'torch'"
  Solution: Use correct Python with torch installed
    PYTHON_BIN=/path/to/python convert_model_format.py ...

Issue: "Could not detect model format"
  Solution: Check if model structure is valid
    ls -la /path/to/model/
