                      RECOMMENDED FIX FOR STATE_DICT ADAPTER
================================================================================

FILE: torchtitan/models/llama3/state_dict_adapter.py

ISSUE:
  The _permute() method fails when the tensor is distributed (sharded)
  because dimension 16 cannot be evenly divided by 48 ranks.

ERROR MESSAGE:
  RuntimeError: Cannot unflatten unevenly sharded tensor:
  output dimension 0 (size 16) is not evenly divisible by mesh dimension 0 (size 48).
  Please redistribute the tensor before this operation.

ROOT CAUSE:
  When loading HF model checkpoints, the state_dict adapter tries to reshape
  tensors that are FSDP-sharded across 48 ranks. The reshape from [2048, 2048]
  to [16, 64, 2, 2048] requires the new first dimension (16) to be evenly
  divisible by the number of ranks (48), which it is not.

CURRENT CODE (Around line 50-52 in state_dict_adapter.py):
───────────────────────────────────────────────────────────────────────────
def _permute(self, value: torch.Tensor, n_heads: int) -> torch.Tensor:
    dim1, dim2 = value.shape
    n_heads_arg = n_heads
    value = value.view(n_heads, -1)
    value = (
        value.reshape(
            n_heads_arg, value.shape[1] // n_heads_arg // 2, 2, value.shape[2]
        )
        .transpose(1, 2)
        .reshape(value.shape)
    )
    return value

PROBLEMATIC OPERATION:
  w.view(n_heads_arg, dim1 // n_heads_arg // 2, 2, dim2)
  │
  └─ Tries to reshape from [2048, 2048] to [16, 64, 2, 2048]
     But tensor is SHARDED across 48 ranks!

SOLUTION (RECOMMENDED):
───────────────────────────────────────────────────────────────────────────

Step 1: Add import at top of file
  from torch.distributed.tensor import DTensor

Step 2: Replace the _permute() method with:

def _permute(self, value: torch.Tensor, n_heads: int) -> torch.Tensor:
    """
    Permute RoPE weights for compatibility with TorchTitan format.
    Handles both replicated and distributed tensor inputs.

    Args:
        value: Tensor to permute (may be distributed)
        n_heads: Number of attention heads

    Returns:
        Permuted tensor in TorchTitan format
    """
    # Convert distributed tensor to local to avoid sharding issues
    # during reshape operations
    if isinstance(value, DTensor):
        value = value.to_local()  # Convert to local tensor on each rank

    # Perform the reshape operation on local tensor
    dim1, dim2 = value.shape
    n_heads_arg = n_heads

    value = value.view(n_heads, -1)
    value = (
        value.reshape(
            n_heads_arg, value.shape[1] // n_heads_arg // 2, 2, value.shape[2]
        )
        .transpose(1, 2)
        .reshape((dim1, dim2))  # Restore original shape
    )

    return value

═════════════════════════════════════════════════════════════════════════════

WHY THIS WORKS:
───────────────────────────────────────────────────────────────────────────

1. to_local() converts distributed tensor to full local copy on each rank
   - Gathers sharded dimensions to have complete tensor
   - No data is lost, each rank gets the full tensor

2. Reshape operation now works on local (non-sharded) tensor
   - No dimension divisibility constraints
   - Standard PyTorch reshape behavior

3. Result is returned as local tensor
   - Automatically synchronized across ranks
   - Ready for subsequent FSDP operations

ALTERNATIVE SOLUTION (If to_local() has overhead):
───────────────────────────────────────────────────────────────────────────

Use redistribute() instead of to_local():

from torch.distributed.tensor import DTensor, Replicate

def _permute(self, value: torch.Tensor, n_heads: int) -> torch.Tensor:
    """
    Permute RoPE weights for compatibility with TorchTitan format.
    Handles both replicated and distributed tensor inputs.
    """
    # Ensure tensor is replicated (not sharded) before reshape
    if isinstance(value, DTensor):
        # Redistribute to replicated spec (no sharding)
        value = value.redistribute([Replicate()])

    # Now perform reshape on replicated tensor
    dim1, dim2 = value.shape
    n_heads_arg = n_heads

    value = value.view(n_heads, -1)
    value = (
        value.reshape(
            n_heads_arg, value.shape[1] // n_heads_arg // 2, 2, value.shape[2]
        )
        .transpose(1, 2)
        .reshape((dim1, dim2))  # Restore original shape
    )

    return value

Note: Replicate() might be more efficient in some cases, but to_local() is
simpler and more straightforward for this use case.
